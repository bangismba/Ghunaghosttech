GHUNAGHOST TECH LTD — brand & icon set
======================================
Every file here is traced from your supplied logo. No shape, proportion
or colour has been altered. Brand blue is #00A7F6, wordmark ink #070B0C.

LOGO
  logo-full.svg            mark + wordmark, for light backgrounds
  logo-full-onDark.svg     same lockup, wordmark in white
  logo-mark.svg            shield only
  logo-full-1420.png       raster export, light backgrounds
  logo-full-onDark-1420.png
  logo-mark-512.png

ICONS
  favicon.svg              master vector, transparent (works on light and dark tabs)
  favicon.ico              16 / 32 / 48 px bundle
  favicon-96.png
  apple-touch-icon.png     180 px, white background (iOS renders transparency black)
  icon-192.png             PWA, artwork inside maskable safe zone
  icon-512.png             PWA
  safari-pinned-tab.svg    monochrome silhouette for pinned Safari tabs
  og-image.png             1200x630 social sharing card
  site.webmanifest

INSTALL
Copy this folder into your site's public root as /brand, then add to <head>:

  <link rel="icon" href="/brand/favicon.ico" sizes="32x32" />
  <link rel="icon" href="/brand/favicon.svg" type="image/svg+xml" />
  <link rel="apple-touch-icon" href="/brand/apple-touch-icon.png" />
  <link rel="mask-icon" href="/brand/safari-pinned-tab.svg" color="#00A7F6" />
  <link rel="manifest" href="/brand/site.webmanifest" />
  <meta name="theme-color" content="#00A7F6" />
  <meta property="og:image" content="https://yourdomain.com/brand/og-image.png" />

CLEAR SPACE
Keep free space equal to the width of the shield on all sides of the lockup.
Minimum lockup width 120 px; below that use the mark alone.
